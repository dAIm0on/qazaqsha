# Қазақша — тренажёр

Личная практика по урокам 1–1, 1–2 и 1–3. Для Кристины и группы курса.

**Сайт:** https://daim0on.github.io/qazaqsha/

Регистрации нет. Прогресс хранится в браузере.

## Как заниматься

1. Открой ссылку.
2. «Учить» → первый шаг → «Понятно → проверить».
3. На телефоне: «Сегодня» → «На телефон и без интернета». Сначала дождись сохранения материалов, затем добавь на экран Домой.
4. Раз в неделю: «Сегодня» → «Резервная копия» → экспорт `progress.json`.

Ссылку лучше не выкладывать в открытый интернет: внутри упражнения курса. Не заменяет официальные тесты BatylBol.
