# Қазақша — тренажёр

Личная практика по урокам 1–1, 1–2 и 1–3. Для Кристины и группы курса.

**Сайт:** https://daim0on.github.io/qazaqsha/

Прогресс хранится в браузере телефона или компьютера. Регистрации нет.

- На телефоне: открой ссылку → «Поделиться / ⋮» → «На экран Домой».
- Резервная копия: в тренажёре «Сегодня» → «Резервная копия» → «Экспорт прогресса». Сохрани `progress.json`.
- Ссылку лучше не выкладывать в открытый интернет: внутри упражнения курса.

Не заменяет официальные тесты BatylBol.
