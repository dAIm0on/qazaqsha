# Qazaqsha — Қазақша

Личная письменная практика по урокам **1–1…2–3**.

**Сайт:** https://qazaqsha.pages.dev/  
Зеркало GitHub Pages (`https://daim0on.github.io/qazaqsha/`) может отставать.

Вход по почте необязателен. Без входа прогресс остаётся в этом браузере. После входа тот же прогресс пишется в облако.

## Как заниматься

1. Открой https://qazaqsha.pages.dev/
2. «Сегодня» → одна зелёная кнопка.
3. На телефоне: «Сегодня» → «Настройки и перенос данных» / «На телефон и без интернета». Сначала дождись сохранения материалов, затем добавь на экран Домой.
4. Раз в неделю: «Сегодня» → «Настройки и перенос данных» → экспорт.

Не заменяет официальные тесты BatylBol. Внутри упражнения курса ссылку в открытый чат не кидать.
