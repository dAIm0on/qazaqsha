## Влияние на прогресс (для 2T-b)

- Каждое слияние = запись в `migrations[].chapter_ids` (старый id → id, который остаётся) + bump `content_revision`.
  Bump ревизии на сайте **сбрасывает пройденный путь урока** (`loadLessonPath`: phase=done → повтор с первой главы),
  поэтому для 3-1…4-2 это надо явно согласовать (вопрос 6). Mastery/skills/records не пересчитываются.
- Проверки глав (`checks[].id`) и их `error_key` сохраняются; при слиянии проверки переходят в оставшуюся главу.
- Стресс-метки, частица да/де/та/те, палитра и экраны ошибок не трогаются.
